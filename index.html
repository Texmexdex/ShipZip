Add ShipZip to your Home Screen first

  1. Tap the Share button ⬆︎ in Safari's toolbar.
  2. Scroll down and tap Add to Home Screen, then Add.
  3. Open ShipZip from the Home Screen and do the setup there.

The Home Screen app keeps its own saved keys, separate from Safari, so anything typed in here won't carry over.

How do I get a token?
  1. Open GitHub → new fine-grained token.
  2. Name it ShipZip and pick an expiration.
  3. Repository access: All repositories (so ShipZip can make new site repos).
  4. Under Repository permissions set to Read and write: Administration, Contents, Pages.
  5. Generate, copy, and paste it above.

The token is stored only on this phone and sent only to GitHub.

2 Your site

A new repository with this name is created on the first deploy. Pick an existing one to update it instead.

How do I get an IONOS API key?
  1. Log in to IONOS and open the Developer API / API Access section.
  2. Tap Create new key, give it a name.
  3. Copy the public prefix and the secret, and paste them here as prefix.secret (with a dot between).

This key can change every DNS record on the account. It stays on this phone and is sent only to IONOS.

Recommended: verify the domain with GitHub
  1. On GitHub open Settings → Pages and tap Add a domain.
  2. Enter the domain. GitHub shows a TXT record — copy its value.
  3. Paste it below and tap Add. Then go back and tap Verify on GitHub.

Verifying stops anyone else from ever hosting a GitHub site on your domain.
